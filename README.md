# Zahidul Islam Zahid Portfolio

Personal portfolio website built from scratch using:
- HTML5
- CSS3
- Vanilla JavaScript

No React, Bootstrap, Tailwind, jQuery or other framework is used.

## Features
- Responsive design
- Mobile navigation
- Dark/light theme switch
- About, Skills, Experience, Projects and Education sections
- Contact section
- Original visual design
